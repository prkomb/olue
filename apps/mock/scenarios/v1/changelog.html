Changelog

What we shipped, week by week. Subscribe to the RSS feed for updates.

v2.3 — March 24, 2026

  • Funnel editor now supports cross-platform steps for iOS, Android, and Web in the same funnel definition.
  • Warehouse sync to BigQuery is now twice as fast for tables over 50 million rows.
  • Fixed a regression where saved dashboards lost their custom date range after browser reload.

v2.2 — March 10, 2026

  • New retention chart with rolling 7, 28, and 90 day cohorts.
  • Slack alerts can now be scoped to a specific dashboard tab.
  • Improved error messages when an event property has the wrong type.

v2.1 — February 24, 2026

  • Added support for SAML SSO via Okta and Azure AD on the Scale plan.
  • Public API rate limits raised to 1,000 requests per minute per workspace.
  • Removed the legacy v1 funnel editor. All workspaces are now on v2.
